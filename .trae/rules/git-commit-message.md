先根据暂存改动所属目录判断改动范围：
- website/ 目录 → 官网（前端）
- miniprogram/ 目录 → 小程序（前端）
- backend/ 目录 → 后端
- docs/、tools/、根目录文件 → 项目基础/文档

提交信息格式「类型: 范围 + 中文描述」，例如：
- feat: 官网新增预约表单
- feat: 小程序新增训练档案页
- fix: 后端修复扫码核销扣次异常
- chore: 小程序升级依赖版本

规则：
1. 类型用 feat / fix / chore / docs / refactor，与改动内容对应
2. 必须带范围标记（官网/小程序/后端/基础），一眼看出改的是哪一端
3. 标题简洁不超过 50 字，类型和描述之间用英文冒号加空格
4. 一次提交只改一个范围；跨范围改动建议拆成多次提交分别提交
